## PID 5304 및 HTML 자동 실행 진단

- PID 5304는 `C:\Program Files\nodejs\node.exe src/server.js`로 실행된 Node 서버이며 `127.0.0.1:3300`을 LISTEN 중
- 부모 PID 2340은 현재 종료되어 있어, `start.bat` 런처와 연결되지 않은 독립 실행 프로세스로 확인됨
- `GET http://127.0.0.1:3300/` 결과는 HTTP 200 및 `text/html`로 정상
- `src/server.js` 자체에는 브라우저를 여는 코드가 없음
- `start.bat`은 새 서버를 성공적으로 시작해 LISTEN 상태를 확인한 뒤에만 `start "" "http://127.0.0.1:%APP_PORT%"`를 실행함
- 이미 PID 5304가 3300을 점유하면 `start.bat`의 `Port ... is already in use` 분기에서 종료하므로 브라우저 자동 실행 단계에 도달하지 않음
- 결론: HTML 제공 실패가 아니라, 기존 독립 서버가 포트를 점유해 런처의 브라우저 실행 분기가 건너뛴 상태

## `start.bat` 기존 PID 자동 정리

- `:startServer`에서 설정 포트의 LISTEN PID를 발견하면 `taskkill /PID <PID> /T /F`로 기존 프로세스 트리를 종료
- 포트가 실제로 해제된 것을 확인한 뒤 새 서버를 시작하도록 `:waitForPortFree` 대기 단계 추가
- 종료 실패 또는 포트 미해제 시 새 서버를 시작하지 않고 중단
